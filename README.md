# 🎯GUESSING GAME

**This project is based on a number-guessing game. It allows you to have fun making attempts and dealing with values ​​randomly chosen by the machine itself.**


## 🛠️ Prerequisites

To run this game on your machine, you need:

- **Python 3.6** or higher (the project relies strictly on Python's standard libraries, so no additional dependencies or `pip install` commands are required).

---

## 🚀 How to Run

1. **Clone this repository** (or download as a ZIP file):
   ```bash
   git clone https://github.com/brunabm24/guessing-game.git
2. **Navigate to the project directory:**
    ```bash
    cd guessing-game
3. **Run the script:**
    ```bash
    python main.py
---

## 🎮How To Play

>**1° -->** The game automatically generates a secret number between 1 and 100.
>
>**2° -->** You have a total of 10 attempts to guess it correctly.
>
>**3° -->** After each guess, the game provides feedback: 
> - Too low: Your guess is smaller than the secret number.
> - Too high: Your guess is larger than the secret number.
>
>**4° -->** Guess correctly before running out of attempts to win!
>
